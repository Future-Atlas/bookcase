# 2026-10-13 検証チェック

本変更の公開先はdevelop / stagingのみ。本番mainにはまだ反映しない。

- Googleログイン：別の回線・別の端末から一度の認証で入れること。同一セッションでIPが変化した場合のガードは継続。検証DBの20261013010000マイグレーション適用成功を先に確認する。
- 書籍下の移動バーは非表示。三角矢印と横スクロールは維持。ページ追加取得中のインジケーターは中央の一つで、利用者のページカラーを使用する。
- PC幅900px以上：検索結果20冊は5列×2行、広告枠、5列×2行。追加20冊でも同じ配置。小さい画面では列数を減らす。
- 検証サイトの広告は黄色枠の「広告（検証用表示・配信なし）」であり、実広告SDKは読み込まない。本番への昇格時は既存の配信設定を使用。広告ブロッカー・在庫不足を回避したり、広告を偽装して表示しない。
- 広告権限確認の一時障害は一定時間後に再確認し、広告非表示権限を迂回しない。SDK自体の通信失敗のみ最大2回再試行する。未充填広告の連続リロードはしない。
- /book/ISBN：人間には同じ書籍詳細ダイアログ、クローラーには書籍情報と公開レビュー。十分な非ネタバレレビューがある本をsitemapに掲載し、それ以外はnoindex。検証環境は全ページnoindexを維持する。検索エンジンでの掲載・順位は保証しない。
- 楽天リンク：Vercel PreviewにRAKUTEN_AFFILIATE_IDを設定して再デプロイ後、該当商品に移動すること。未設定・取得不能なら非表示。
- サブスク公開フラグは無効のまま。
