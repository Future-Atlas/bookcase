# ホームの自動移動・検索流入の修正（2026-10-19）

関連Asana: https://app.asana.com/1/1214959235757981/project/1214959849575459/task/1219635925965917

## 今回の変更

- 画面内に見えているすべての書籍セクションが、1.5秒間隔で1冊分（150px）移動する。
- APIは従来の9冊単位で先読みする。既存の列へ重複を除いて追加し、現在のスクロール位置を保つ。通信中は確保済みの本を残す。
- クリック・ドラッグ・ホイール・矢印操作による10秒の停止は、そのセクションだけに適用する。書籍ダイアログを開いた時間は、そのセクションの再開待ちに含めない。
- 画面内に複数の書籍セクションが見えている場合は、見えている各セクションを独立して自動移動する。
- 通常URL `/book/ISBN` と旧形式 `/#/book/ISBN` を、アプリ起動時の書籍ルートへ引き継ぐ。
- 楽天APIの一時的な通信失敗を永続的に「本がない」とキャッシュしない。
- 書籍URL経由でも広告利用権限の確認を行い、広告表示可能な利用者の広告枠を初期化する。
- アプリ内広告枠に閉じる操作を追加。同じタブのセッション内ではその枠を再表示しない。広告DOM内の固定配置が枠外へ描画されることを抑制する。
- 日本語HTMLに `google=notranslate` を追加。

## 外部確認が残る項目

- 下部バナーが広告事業者によってアプリの広告DOM外へ追加されている場合、この閉じる操作の対象にはならない。実配信で確認し、必要なら配信事業者側のオーバーレイ形式を変更する。
- PCの通常DNS経路では旧Vercelの404、Cloudflare（104.21.36.179）へ接続した同じ書籍URLでは200を確認。DNSキャッシュの更新またはPCのDNS設定変更が必要。コード変更では旧接続先へ到達する端末を修復できない。
- GitHubのWebsiteはすでに `https://www.sharemarium.com/`。公開GitHubページが検索結果に出るかはこのサイトから制御できない。
- 既存の旧Vercel URL用308リダイレクト、公式canonical、sitemapは維持。検索結果の更新は再クロール後に確認する。
- Google翻訳の表示抑制は、公開後のスマホで再確認する。

## 公開前の実機確認

1. ホームで人気作品・新着・洋書を順に表示し、対象セクションだけが1冊ずつ進むことを確認。
2. 一つのセクションを操作して、別セクションへスクロールする。操作していないセクションが停止しないことを確認。
3. 書籍情報を開いて10秒以上待ち、閉じた後に停止時間が改めて始まることを確認。
4. 9冊の境界をまたいでも一覧が先頭へ戻らず、追加の本へ進むことを確認。
5. `/book/9784101269313` を直接開く・リロードする・旧ハッシュURLから開く。対象の本が開き、閉じた後は通常のホームを操作できることを確認。
6. 広告枠を閉じ、画面再訪・リロード時にもそのタブ内では非表示になることを確認。広告非表示権限のある利用者には枠自体が出ないことも確認。

DBマイグレーションやDNSの変更は含まない。
