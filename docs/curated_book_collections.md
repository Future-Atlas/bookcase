# 書籍のテーマ別コレクション（実装前の設計）

映画化・アニメ化・受賞歴は、書名のキーワードや書籍APIのジャンルだけで断定しない。
運営者が一次資料（賞の公式サイト、出版社・映画公式サイト等）を確認し、
作品と出典を記録したものだけを公開する。空の分類は表示しない。

## 分類

- 現在映画化されている作品の原作
- 過去に映画化された作品の原作
- AIを学ぶ
- 金融を学ぶ
- 本屋大賞
- 直木賞
- 芥川賞
- アニメ化された作品の原作漫画

「現在映画化」は基準日が変わるので、上映開始・終了日を明記して定期的に見直す。
賞は受賞年、賞の名称、受賞・候補の区別を保存する。学習分野は運営者の選書として表示する。

## データと表示の流れ

1. 運営者が作品名、著者、分類、根拠URL、確認日、必要なら受賞年・公開期間を登録する。
2. ISBNが判明していればISBNで楽天の書誌を照合する。ISBNのない作品や版が複数ある作品は、タイトルだけで自動確定せず、著者と版を人が確認する。
3. 出典のある分類情報は自前のデータとして保持し、表紙・出版社などの書誌は既存APIから取得する。APIが一時停止しても分類の根拠は消えない。
4. 表示前に既存の年齢制限・書誌表示ルールを適用し、未確認・非公開・期間外・書誌未照合の作品は公開リストに出さない。

将来のDBでは、分類（slug、名称、説明、公開状態、並び順）と分類内の作品
（作品ID、ISBN、根拠URL、確認日、受賞年、期間、公開状態、並び順）を分ける。
一般ユーザーは公開済み項目の読み取りだけ、編集は管理権限のある操作だけに限定する。
データ取得・権限・RLS・既存書籍IDとの互換性を検証してから別PRで導入する。

映画・賞の一覧は情報源の利用条件も確認する。受賞作品や原作の関係を推測で作らない。
